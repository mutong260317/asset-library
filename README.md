# 资产产品分析（Asset Library）
个人资产配置研究系统：剖析每只 ETF 的**底层结构 → 康波周期定位 → 估值位置 → 宏观环境**，以「周期为王、不硬配比例」为核心方法论，输出 A股/美股各自按 100% 计的配置方案。
## 架构（三层）
| 层 | 文件 | 作用 |
|---|---|---|
| 数据层 | `data.js` | 资产档案的规范源（纯数据），可被网页、飞书文档、后续分析复用 |
| 展示层 | `index.html` | 数据驱动的交互式资产库网页（筛选/排序/温度计/图表），本地可直接打开，可部署 GitHub Pages |
| 版本层 | git + GitHub | 版本控制与数据同步，每次修改 commit 并 push，历史可追溯 |
| 阅读版 | 飞书文档《资产配置方案 v2》 | 对外阅读/协作版，关键结论定期同步 |
## 更新工作流
1. 分析新资产 → 在 `data.js` 中补充档案（底层结构/周期定位/估值分位/三档配置）——**`data.js` 是唯一规范源**
2. 把 `data.js` 内容同步为 `index.html` 内嵌数据快照（保证本地双击即可打开、不依赖网络）
3. 本地打开 `index.html` 验证渲染与数据正确
4. `git add . && git commit -m "..."` → `git push`
5. 关键结论同步到飞书文档
## 方法论：四层分析法
1. **底层结构**：锚定什么、收益来源、久期/贝塔
2. **康波定位**：处于康波哪一段（回升/繁荣/衰退/萧条）+ 基钦/朱格拉中周期
3. **估值位置**：PE/PB 近 5–10 年分位、股息率、CAPE → 便宜/合理/贵
4. **宏观环境**：利率周期（降息/加息）、地缘政治、流动性
时间维度分三档推演：**1–3 年（短周期买卖节奏）、3–5 年（中周期大类切换）、5–10 年（康波赛道选择）**。
## 决策规则（不硬配比例）
- 周期上行早期 + 估值低位 → 超配/分批建仓
- 周期上行中段 + 估值合理 → 标配/持有
- 周期顶部 + 估值高位 → 减配/落袋/暂缓
- 周期下行 + 估值仍高 → 现金/防御/等待
## 数据源
- 实时估值/行情：豆包金融搜索（同花顺数据合作）
- 估值分位：中证指数官网、理杏仁 API、雪球/指数估值周报
- 历史数据/宏观：AkShare、FRED、GitHub 开源（aiagents-stock 康波模块、global-equity-valuations-api）
