## 主要发现与处理

| 优先级 | 发现 | 处理 |
|---|---|---|
| P1 | 结构校验失败后仍渲染配置 | 数据、校验器缺失或校验失败时暂停全部数据视图，深链接也不能绕过 |
| P1 | 观察标的名称/备注直接拼入 HTML | 校验证券代码和字段长度，对渲染字段转义，验证存储型注入不执行 |
| P1 | 产品发布校验仅检查 checked 项，遗漏缺价资产 | 严格发布要求全部产品有核验价格且属于最近已收盘日 |
| P1 | 长桥展示格式缺原始时间戳 | 改读官方 serve JSON-RPC，按请求 ID 匹配批量响应，保留日线复权口径 |
| P1 | 部分时段 global 线路连接失败 | 仅连接错误时尝试同一提供商的 cn 线路；失败保留原数据 |
| P1 | 真实份额拆分被当作价格异常 | 依据 SEC 记录 MTUM 4:1、SOXX 3:1，严格限定证券与生效日，仅规范化相邻日校验收益，保留原始 OHLC |
| P1 | 产品和回撤分别写入，可能只更新一半 | 隔离候选全量获取及校验，同一可恢复事务写入产品、回撤和状态 |
| P1 | 总览的档案被放在隐藏的资产页内 | 改为全站原生 dialog，支持关闭、Escape 和键盘入口 |
| P1 | 缺少仓库内可验收的飞书发送器 | 增加预览、显式发送、意图持久化、固定 UUID、回执确认及事件 ack |
| P2 | 历史变化箭头方向与数值相反，混合周次却标为本周对比 | 修复箭头与颜色，补周次，按周倒序展示 |
| P2 | 固定写死的溢价数字与研究日期脱节 | 删除渲染层旧数字，按资产记录展示日期和未知状态 |
| P2 | 科技穿透使用固定乘数展示 | 展示可直接复算的所列 ETF 权重之和，穿透估算保持待核验 |
| P2 | 最新周报缺少页面入口 | 从实际文件生成周报索引，保留早期摘要 |
| P2 | 导航无法正常使用浏览器返回，部分操作缺键盘支持 | 使用原生链接/hashchange，补市场按钮、排序、档案和清单语义 |
| P2 | 重复评分统计掩盖行情覆盖 | 总览分别显示两个市场的产品价格覆盖和收盘日期范围 |
